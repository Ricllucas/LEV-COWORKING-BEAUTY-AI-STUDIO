# Projeto LEV

Pasta central dos materiais locais da LEV, consolidada em 31/10/2026.

Abra `LEV.code-workspace` para trabalhar com uma única pasta de projeto.

- `sistema`: repositório com o commit mais recente encontrado, de 30/09/2026. Histórico Git e alterações locais preservados.
- `historico`: outras versões do sistema, ferramentas e arquivos anteriores. Não foram misturadas alterações de versões diferentes no código principal.
- `automacoes`: aplicativo de Instagram, squads, roteiros, filas e scripts.
- `infraestrutura-e-pesquisas`: implantação de WhatsApp/Evolution, acesso Oracle, propostas e pesquisa Bela360.
- `marca`: logos, fotos, imagens dos ambientes e perfil.
- `recebidos`: arquivos originalmente em Downloads.
- `auditoria`: mapa das origens e conferência de integridade.

## Uso

O aplicativo principal está em `sistema`. Seus comandos continuam definidos no respectivo `package.json`.
Os scripts antigos de automação foram preservados como recebidos e podem conter caminhos absolutos anteriores; sua execução exige revisar esses caminhos e as integrações compartilhadas do Opensquad/n8n. Nenhuma publicação, implantação ou automação foi disparada nesta consolidação.

As configurações locais e credenciais existentes foram preservadas. O conteúdo desta pasta não foi enviado a serviços externos.

## Escopo

Busca nas pastas locais de trabalho do usuário, Documents/Codex, Squads100, Downloads, Desktop, OneDrive, cópia de Downloads e pastas de projetos na raiz do perfil. Diretórios do sistema, caches de aplicativos e histórico de chats não constituem arquivos de projeto migrados. O projeto LEV COWORKING do ChatGPT continua no serviço; esta consolidação reúne os arquivos locais, sem fundir conversas ou alterar projetos em nuvem.
